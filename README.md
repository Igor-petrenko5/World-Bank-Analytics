# World Bank Analytics

Автоматизированная информационно-аналитическая система
мониторинга социально-экономического развития стран мира.

## Цель проекта

Сбор, обработка, хранение, анализ и визуализация
данных Всемирного банка.

## Источник данных

World Bank Open Data API:
https://api.worldbank.org/v2

## Технологии

- Python
- PostgreSQL
- Apache Airflow
- Docker
- Yandex DataLens
- SQL

## Структура проекта

- src - Python-код
- sql - SQL-запросы
- dags - Airflow DAG
- tests - тесты
- data - данные
- docs - документация

## Статус

Этап 1: подготовка среды разработки.
